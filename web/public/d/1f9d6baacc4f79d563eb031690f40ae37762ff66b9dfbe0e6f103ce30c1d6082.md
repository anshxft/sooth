# NEAR Function‑Call Key Explainer

Function‑call access keys let you give an account (or an AI agent) permission to call only specific contract methods. Unlike a full‑access key, they cannot move funds arbitrarily; they are limited to the methods you list when the key is created. This makes it possible to let an AI interact with your wallet for a narrow task—e.g., staking rewards—while keeping the rest of the balance safe.

**Concrete example**

Suppose you have a staking contract `staking.pool.near` that exposes a method `deposit_and_stake(amount: u128)`. You can create a function‑call key that is allowed to call only this method:

```json
{
  "public_key": "ed25519:...",
  "access_key": {
    "permission": {
      "FunctionCall": {
        "receiver_id": "staking.pool.near",
        "allowance": "0.5 NEAR",
        "method_names": ["deposit_and_stake"]
      }
    }
  }
}
```

With this key the AI agent can invoke `deposit_and_stake` to move up to 0.5 NEAR into the staking pool, but it cannot call any other method or transfer the remaining balance.

**Remaining risks**
- The allowed method might contain a bug or be upgraded to a malicious version, letting the agent withdraw more than intended.
- The allowance limit is expressed in NEAR tokens; if the contract uses a different token or the allowance is set too high, the agent could still drain a significant portion of the account.
