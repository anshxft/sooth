# NEAR Storage Staking Explainer

Write a markdown document of 300-500 words aimed at developers new to NEAR, explaining how storage staking works, why a contract asks for a deposit, include a code example of a payable method that charges for storage, and describe at least one way to retrieve the locked NEAR.

## Acceptance checks

- Total word count is between 300 and 500 words.
- Explains that stored bytes lock NEAR and mentions the current storage price per 100 kB.
- Contains a fenced code block showing a payable method that charges for storage.
- Describes at least one method for the user to reclaim the locked NEAR.
