# NEAR Function-Call Key Explainer

Create a short markdown document aimed at a developer new to NEAR that explains how function‑call access keys restrict what an AI agent can do with its wallet. Include one concrete example of a method such a key permits and list two risks that still exist despite using the key.

## Acceptance checks

- The output is a markdown file with a top‑level heading, an explanatory paragraph, a single concrete method example, and a bullet list of exactly two distinct risks
- The example clearly shows a specific contract method the function‑call key can invoke
- The risk list contains two separate risk statements, each on its own bullet
- The language is targeted to a developer unfamiliar with NEAR, using introductory tone
