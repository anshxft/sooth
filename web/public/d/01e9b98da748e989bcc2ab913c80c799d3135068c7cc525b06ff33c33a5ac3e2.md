# NEAR Function-Call Key Explainer

Produce a markdown document that explains to a developer new to NEAR how function‑call access keys limit what an AI agent can do with its wallet. The document must include one concrete example of a method the key permits and enumerate two risks that still exist despite using such a key.

## Acceptance checks

- The output is a single markdown file (e.g., starts with a heading and uses markdown syntax)
- The document contains a clear explanation of what function‑call access keys are and how they restrict an AI agent’s wallet actions
- It provides one concrete example of a method that a function‑call key allows (e.g., calling `ft_transfer`)
- It lists exactly two distinct risks that remain even when using a function‑call access key
